# 01 — 完整的关卡配置：黑烟囱墓场 / 沉船幽谷

Status: resolved (第一关完整；第二关的"附着与挤压"是下一轮)

## 关卡

`config/levels.json5` 现在只有两关，都是按设计写的：

    黑烟囱墓场 black-smokers   1500m / 30 m/s   BOSS 烟囱蟹王 @1300  140 血   26 条时间线
    沉船幽谷   wreck-gorge     1100m / 32 m/s   BOSS 寄居沉船章鱼 @950  220 血   23 条时间线

两关的地标、节奏取向和内容取向都写进了文件里的注释（第一关是教学关：慢、威胁读得懂；第二关更窄、两侧同时来东西、
而且第一次出现**会转向的**敌人）。起始关卡也改成了 `black-smokers`。

## 新增的敌人 / 环境物

五个新 hazard + 一个障碍，每一个都按仓库的约定补齐了所有表（血量、质量、可食档位、怒气冲击波、喷吐弹药、图鉴名与卡片）：

| 种类 | 是什么 | 实测 |
|---|---|---|
| `vent` **热液喷口** | 第一关的招牌：喷口上方是**致命柱**，周期性喷发 | 静默期站进去 **0 次命中**；喷发期 **5 点伤害 → 直接死亡** ✓ |
| `mineral` **矿物颗粒** | 随热流**上升**的颗粒，最基础的环境弹幕（只有它一个往上走） | 3 秒内上升 **350m**，横向只飘 6m ✓ |
| `shrimp` **盲眼虾** | 从侧面缓慢靠近、不追踪、一戳就破 | 3 秒横移 **−90m**、几乎不下沉 ✓ |
| `angler` **灯笼鱼** | 吊着发光诱饵悬停，靠近后张口冲刺（复用冲锋的曲线几何） | 3 秒内**触发了扑击** ✓ |
| `torpedo` **失控鱼雷** | 先直飞一段，**然后转向追踪** | 直飞 **221m**（配置 220）后开始追 ✓ |
| `tube` **管虫群** | 障碍：一丛会开合的管子，受刺激才伸出来；缝比网窄 | 画成活的管丛（冠会开合），血量 3.0 / 半径 0.075 ✓ |

**热流乘升**是这一关的教学核心，所以它的公平性写在配置和画法里：喷发是**周期性**的（`periodSeconds` 4.2 / 喷 2.6 秒），
喷发**之前**烟流会变亮，喷发**期间**才画出**危及范围的边界线**——画出来的就是判定框，两者读的是同一个 `phase`，
不存在第二个会跑偏的计时器。
