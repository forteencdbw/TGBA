# 原样开局：弹幕退场，玩家从普通小气泡开始

## 1. 这句话

**开局没有形态可选的时候，就不弹形态选择器——玩家直接是一个没有特殊效果的小气泡。** 形态是通关之后
才拿到的东西。

---

## 2. 为什么

owner 的原话：

> 弹幕就不是一个路线了，因为现在所有枪的升级都是共享的，对于玩家来说，就是"一开始没有特殊效果的小气泡"，
> 通关以后才会获得专属的暴怒气泡强化。

所以这不是"加一个解锁系统"，而是**把那个永远可用的格子从「弹幕」换成「小气泡」**，并且让玩家在还没
有得选的时候根本看不到那一屏。

---

## 3. 现状（查证过，其中三条改变了任务的形状）

| 事实 | |
|---|---|
| **解锁机制早就存在，而且正是想要的** | `formsUnlocked(cleared, 'dawn-surface')`：把最后一关打通一次，`吞噬` / `沸腾` 一起解锁。`main.ts` 的注释原话："The two evolved forms are locked until the campaign has been cleared once, and they are LISTED while locked." |
| **"普通气泡"这个状态也早就存在** | `run.route === null` 时 `rollMutationChoices` 只出 `routes: 'all'` 的卡；`forgetForm()` 就是回到它；`defaultBubbleType()` 返回 `BASE_TYPE`。不需要新状态 |
| **弹幕的 +1 是唯一一个"选中即到账"的数值加成** | `pickRoute` 里 `if (route.id === 'barrage')` 那一行。devour 只调 `applyHealthBand()`（非生长形态直接 return），boil 没有任何分支 |
| **`forgetForm` 的注释靠那个加成自证存在** | 它说"不能让 `pickRoute` 重复发放弹幕那一排"。函数仍然需要（新一局必须从基础形态开始），但理由要换 |
| **`枪管` 卡对弹幕永远不可用** | `available: gunStreams < maxStreams`，而弹幕一进场就是 2 排 = 上限。所以那条路上这张卡从来抽不到——删掉加成之后它反而**多出一张可抽的卡** |
| **`maxStreams` 是 2** | 它之所以是 2，正是因为有一条路白送一排。没有形态再被白送之后，2 意味着 `枪管` 卡一局只能拿一次 |
| **锁的显示会因此休眠** | 选择器只在已解锁时出现 → 出现时每一项都是解锁的 → `locked` 恒为 false，「通关一次解锁」永远不会被画出来 |

---

## 4. 决策

### 4.1 弹幕退场，第三格是小气泡

`'barrage'` 从 `RouteId` 和 `ROUTES` 里彻底删掉。选择器第一格直接是 `BASE_TYPE`，标题「原样开局」。

`BASE_TYPE.tagline` 原本写着「身份等到水里再定」——那句话在选择器把身份移到水之前那天起就不对了，改成
「什么都不加 —— 枪、成长、操作，全靠这一局自己挣」。

### 4.2 八张枪卡全部转 `'all'`

大弹丸 / 射程 / 追踪弹，加上霰弹支线五张。理由就是 owner 那一句"所有枪的升级都是共享的"——枪是每个形态
的基础武器，所以深化枪的卡属于每个形态。这和 `子弹速度` 注释里早就写过的理由是同一条（它是第一张被
放开的枪卡）。

普通气泡的池子因此从 10 张变成 18 张合法卡，两条进化路线各厚了 8 张。

### 4.3 `maxStreams` 2 → 3

它是 2 是因为有一条路白送一排、而 `枪管` 卡拿一次就到顶。没有白送之后，2 会让这张卡一局只能拿一次。
现在是两步升级：1 → 2 → 3 排。

### 4.4 没得选就不弹选择器

`开始游戏` 走 `startFromMenu()`：`hasFormChoice()` 为假（战役还没通关）时，直接把 `selectedRoute`
设成 `null` 并开始加载——也就是按下「原样开局」会得到的那个状态；为真时才开选择器。

**一个判据两个用途**：`hasFormChoice()` 同时是触发条件和锁的规则，所以"屏上全是锁的时候还弹"和
"有东西解锁了却不弹"都不可能发生。

### 4.5 锁的显示保留、休眠

`locked` 恒为 false，灰化与「通关一次解锁」画不出来了。**保留而不是删除**：它正是将来做分段解锁
（一个里程碑一个形态）时要画的东西，而一条休眠分支不花任何代价。这一点在 `formOptions` 里写明了。

## 8. 留给 owner 的

**手玩时会看到的**：

- 新存档（没通关过）按开始游戏**直接下水**，看不到形态选择器；开局就是普通小气泡，1 排枪。
- 通关一次之后再按开始游戏，选择器会出现，三格：原样开局 / 吞噬 / 沸腾。
- `枪管` 卡现在可以拿两次（1 → 2 → 3 排）。
- 八张枪卡（大弹丸/射程/追踪/霰弹五张）现在所有形态都抽得到。

**接受的代价**：新玩家永远看不到那两个未解锁的形态——游戏不再展示它扣着什么。旧注释里"看不见目标就
没有目标"那条论据这次是**输了**，换来的是开局落在水上而不是一屏锁着的门。

**一个副作用**：`e2e/helpers.ts` 的 `startFromMenu` 自选择器引入起就过不去 `formPick`，因为没人回答
选择器——上一轮记录过的那处陈旧。空存档现在没有选择器，所以从菜单开始的 spec 又能走到水里了。
